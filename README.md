# Tulas International School — Homepage Redesign

A modern, responsive and animated homepage redesign for **Tulas International School (TIS), Dehradun**.

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- JavaScript

## Features

- Responsive design for desktop, tablet and mobile
- Animated hero section
- Scroll-based animations and parallax effects
- Light / dark mode
- Sports, rankings and testimonials sections
- Responsive navigation
- Enquiry and Apply Now CTAs
- Reduced-motion accessibility support

## Getting Started

```bash
git clone https://github.com/mayankgenwa/TIS-Redesign.git
cd TIS-Redesign
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
